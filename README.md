# Recomp Haven media

Pictures and theme music for the game pages on [recomphaven.com](https://recomphaven.com), served by GitHub Pages
at https://rikuwru.github.io/recomphaven-media/.

- `backdrops/<game page name>/` — a few pictures per game, shown out of focus behind its page and details window.
- `music/<game page name>.mp3` — the game's main theme, played quietly on its page.

Which files a game uses, and how, is listed in `data/media.js` in
[rikuwru/recomphaven](https://github.com/rikuwru/recomphaven). Screenshots, artwork and music belong to their
publishers and composers. To ask for something to be removed, open an issue on this repository.
